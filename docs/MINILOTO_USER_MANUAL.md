# 미니로또 분석 내비 사용 설명서

> 일본 미니로또 분석·번호 생성 보조 도구 사용법입니다.  
> 이 도구는 당첨을 보장하지 않으며, 과거 데이터 기반 통계·백테스트·조합 생성 보조용입니다.

---

## 1. 가장 쉬운 사용 순서

처음 사용한다면 아래 순서만 따라 하세요.

1. **대시보드**에서 최신 회차가 맞는지 확인합니다.
2. **이번 주 참고 점수 TOP 10**을 봅니다.
3. **고급/백테스트**에서 참고 점수가 왜 높은지, 랜덤 기준선보다 나은지 확인합니다.
4. **번호 생성**에서 기본값으로 번호를 생성합니다.
5. 마음에 드는 번호를 **인쇄목록에 추가**합니다.
6. **마크시트/인쇄**에서 출력합니다.
7. 추첨 후 **당첨 확인**에서 내 번호를 확인합니다.

### 초보자 추천 기본 설정

| 항목 | 추천값 |
|---|---|
| 생성 방식 | 균형형 |
| 생성 구수 | 10구 |
| 합계 범위 | 55 ~ 105 |
| 홀짝 조건 | 홀수 3개 |
| 최대 연번쌍 | 2 |
| 동일 끝자리 최대 | 2 |
| 최근회 중복 최대 | 2 |

## 2. 메뉴별 역할

| 메뉴 | 용도 |
|---|---|
| **대시보드** | 최신 결과, 최근 10회, 참고 점수 TOP 10, 핫/미출현/상성 요약 확인 |
| **사용 가이드** | 초보자용 사용법, 용어 설명, 기능별 안내 |
| **데이터** | 전체 결과 DB 확인, CSV 업로드, CSV 붙여넣기, 수동 회차 추가 |
| **통계/상성** | 번호별 출현, 보너스 출현, 미출현, 위치별 랭킹, 상성, 분포 확인 |
| **고급/백테스트** | 확률 모델 점수, 히트맵, 네트워크, 패턴 탐지, 백테스트, 스마트 소거, 시뮬레이션 |
| **번호 생성** | 조건을 걸고 실제 구매 후보 조합 생성 |
| **커버리지** | 후보 숫자 풀 안에서 조합을 효율적으로 구성 |
| **당첨 확인** | 내 번호와 실제 결과를 비교해 등수 판정 |
| **마크시트/인쇄** | 구매 전 보조 마킹표 출력 |
| **운영 계획** | 향후 서비스화 로드맵 확인 |

## 3. 대시보드 사용법

대시보드는 가장 먼저 보는 화면입니다.

### 확인할 것

1. **총 회차 / 최신 추첨일**  
   데이터가 최신인지 확인합니다.

2. **최신 결과**  
   본숫자 5개와 보너스 숫자를 확인합니다.

3. **이번 주 참고 점수 TOP 10**  
   모델이 현재 데이터 기준으로 점수를 높게 준 숫자입니다.

4. **핫 넘버 TOP 8**  
   과거 출현이 많았던 숫자입니다.

5. **장기 미출현 TOP 8**  
   최근 오래 나오지 않은 숫자입니다.

6. **상성 페어 TOP 8**  
   같이 자주 나온 숫자쌍입니다.

### 해석 주의

핫 넘버나 참고 점수는 미래 당첨 보장이 아닙니다.  
단순히 “현재 데이터에서 참고할 만한 숫자”입니다.

## 4. 데이터 업데이트 방법

### 방법 A. CSV 업로드

1. **데이터** 탭으로 이동합니다.
2. `CSV 파일 업로드`에서 파일을 선택합니다.
3. 자동으로 데이터가 반영됩니다.

지원 형식 예:

```csv
draw,date,n1,n2,n3,n4,n5,bonus
1397,2026/7/28,03,06,14,20,31,17
```

### 방법 B. CSV 붙여넣기

1. CSV 내용을 복사합니다.
2. **CSV 붙여넣기** 칸에 붙여넣습니다.
3. `붙여넣은 CSV 반영` 버튼을 누릅니다.

### 방법 C. 한 회차 수동 추가

1. **수동 최신회 추가/수정** 영역으로 갑니다.
2. 회차, 날짜, 본숫자 5개, 보너스 숫자를 입력합니다.
3. `추가/수정 저장`을 누릅니다.

### 입력 규칙

- 본숫자 5개는 1~31 사이여야 합니다.
- 본숫자 5개는 서로 중복되면 안 됩니다.
- 보너스 숫자도 1~31 사이여야 합니다.
- 보너스 숫자는 본숫자와 중복되면 안 됩니다.

## 5. 통계/상성 보는 법

### 번호별 종합 랭킹

각 숫자에 대해 다음을 보여줍니다.

| 항목 | 의미 |
|---|---|
| 본숫자 | 본숫자로 나온 횟수 |
| BO | 보너스 숫자로 나온 횟수 |
| 최근 | 최근 N회 안에서 나온 횟수 |
| 미출현 | 마지막 출현 이후 나오지 않은 회차 수 |
| 평균간격 | 과거 출현 간격의 평균 |
| 점수 | 여러 통계를 합친 참고 점수 |

### 위치별 등장 랭킹

미니로토 번호는 정렬된 상태로 제1~제5 숫자가 됩니다.

예: `03 06 14 20 31`

- 제1숫자: 03
- 제2숫자: 06
- 제3숫자: 14
- 제4숫자: 20
- 제5숫자: 31

위치별로 자주 나온 숫자를 확인할 수 있습니다.

### 상성 분석

기준 숫자를 선택하면, 그 숫자와 함께 자주 나온 숫자를 보여줍니다.

예:

> 31번과 20번이 자주 같이 나왔다.

이것은 미래에도 같이 나온다는 뜻은 아니고, 과거 동시 출현 횟수입니다.

## 6. 고급/백테스트 사용법

이 탭은 사이트의 핵심입니다.

### 6-1. 확률 모델 대시보드

각 숫자의 다음 회 기대 점수를 0~100점으로 보여줍니다.

점수에 반영되는 요소:

- 누적 출현 빈도
- 최근 출현 강도
- 현재 결석 회차
- 평균 출현 간격과의 근접도
- 보너스 출현 이력

### 점수 옆 설명 예시

| 설명 | 의미 |
|---|---|
| 최근 출현 강함 | 최근 회차에서 자주 나왔음 |
| 결석 기간 상승 | 최근 나오지 않은 기간이 길어지고 있음 |
| 평균 간격에 근접 | 과거 평균 출현 간격과 현재 결석 기간이 비슷함 |
| 누적 빈도 우위 | 전체 기간에서 비교적 많이 나왔음 |

### 6-2. 다차원 히트맵

숫자 × 위치 × 최근 N회를 색상으로 표시합니다.

- 색이 진할수록 많이 나온 위치입니다.
- 모바일에서는 좌우로 스크롤해서 봅니다.

### 6-3. 상성 네트워크 그래프

숫자 간 동시 출현 관계를 그래프로 보여줍니다.

- 선이 굵을수록 같이 나온 횟수가 많습니다.
- 상위 간선 수를 조절할 수 있습니다.

### 6-4. 백테스트 엔진

과거 데이터를 기준으로 예방법을 검증합니다.

지원 전략:

- 균형형
- 핫 중심
- 미출현 중심
- 최근 추세
- 상성 중심
- 콜드 역발상
- 랜덤 기준선

### 백테스트 결과 해석

| 항목 | 의미 |
|---|---|
| 선택 전략 4등+ | 선택한 전략으로 생성한 조합 중 4등 이상 비율 |
| 랜덤 기준선 | 같은 구수로 랜덤 생성했을 때의 결과 |
| 차이값 | 선택 전략이 랜덤보다 얼마나 높거나 낮은지 |
| 전략 구 평균 | 조합 1구당 평균 일치 숫자 수 |
| 회차 단위 적중 | 한 회차에 여러 구를 샀을 때 4등 이상이 하나라도 있었던 비율 |

### 좋은 해석 방법

전략 결과가 랜덤보다 높게 나왔다고 해서 미래에도 반드시 좋다는 뜻은 아닙니다.  
다만 여러 전략을 비교할 때 참고할 수 있습니다.

## 7. 번호 생성 사용법

### 기본 사용

1. **번호 생성** 탭으로 이동합니다.
2. 생성 방식을 고릅니다.
3. 생성 구수를 입력합니다.
4. 필요하면 고정 숫자와 제외 숫자를 입력합니다.
5. `참고 번호 생성`을 누릅니다.
6. 결과를 점수순/합계순/홀수순으로 정렬합니다.
7. 마음에 드는 조합을 인쇄목록에 추가합니다.

### 생성 방식 설명

| 생성 방식 | 설명 |
|---|---|
| 균형형 | 빈도, 최근성, 결석, 상성을 골고루 반영 |
| 핫 중심 | 자주 나온 숫자에 가중치 |
| 미출현 중심 | 오래 나오지 않은 숫자에 가중치 |
| 콜드 역발상 | 적게 나온 숫자를 역발상으로 반영 |
| 최근 추세 | 최근 회차 흐름을 더 강하게 반영 |
| 상성 중심 | 같이 자주 나온 숫자쌍을 더 반영 |
| 순수 랜덤 | 통계 가중치 없이 무작위 생성 |

### 고정 숫자 / 제외 숫자

- **고정 숫자**: 반드시 포함하고 싶은 숫자
- **제외 숫자**: 빼고 싶은 숫자

예:

```text
고정 숫자: 03 14
제외 숫자: 04 09 21
```

### 숫자 보드 사용

숫자 버튼을 클릭하면 상태가 바뀝니다.

1. 한 번 클릭: 고정
2. 두 번 클릭: 제외
3. 세 번 클릭: 해제

## 8. 스마트 소거 시스템

스마트 소거는 조건에 맞는 후보 숫자만 남기는 기능입니다.

설정 항목:

| 항목 | 의미 |
|---|---|
| 최소 모델점수 | 이 점수 이상만 남김 |
| 최소 결석 | 적어도 이 회차 이상 안 나온 숫자만 남김 |
| 최대 결석 | 너무 오래 안 나온 숫자는 제외 |
| 제외 끝자리 | 특정 끝자리 숫자를 제외 |
| 직전 회차 제외 | 바로 전 회차에 나온 본숫자 제외 |

결과 버튼:

- **커버리지 풀로 보내기**: 남은 숫자를 커버리지 후보 풀에 넣음
- **퀵픽 제외조건으로 보내기**: 남지 않은 숫자를 제외 조건으로 넣음

## 9. 커버리지 사용법

커버리지는 후보 숫자 풀 안에서 여러 조합을 효율적으로 구성하는 기능입니다.

예를 들어 후보 숫자 10개가 있을 때, 가능한 모든 5개 조합을 다 살 수는 없습니다.  
이때 제한된 구수 안에서 3개 조합 또는 4개 조합을 최대한 넓게 덮도록 조합을 고릅니다.

### 사용 순서

1. 후보 풀 숫자를 입력합니다.
2. 최대 구수를 정합니다.
3. 목표 커버를 3개 또는 4개 조합으로 선택합니다.
4. `커버리지 계산`을 누릅니다.
5. 결과가 마음에 들면 인쇄목록에 추가합니다.

### 결과 해석

| 항목 | 의미 |
|---|---|
| 커버율 | 후보 풀 안의 부분 조합 중 몇 %를 덮었는지 |
| 구수 | 선택된 구매 조합 수 |
| 효율 | 한 구당 평균적으로 덮은 부분 조합 수 |

주의: 커버리지는 당첨 보장이 아닙니다. 후보 풀 안에서 조합 분산을 돕는 도구입니다.

## 10. 당첨 확인 사용법

1. **당첨 확인** 탭으로 이동합니다.
2. 확인할 회차를 선택합니다.
3. 내 번호를 한 줄에 5개씩 입력합니다.
4. `확인하기`를 누릅니다.

예:

```text
03 06 14 20 31
04 08 09 16 30
01 10 17 20 31
```

### 판정 기준

| 등수 | 조건 |
|---|---|
| 1등 | 본숫자 5개 일치 |
| 2등 | 본숫자 4개 + 보너스 일치 |
| 3등 | 본숫자 4개 일치 |
| 4등 | 본숫자 3개 일치 |

---

## 11. 마크시트/인쇄 사용법

1. 번호 생성나 커버리지 결과에서 `인쇄목록 추가`를 누릅니다.
2. **마크시트/인쇄** 탭으로 이동합니다.
3. 목록을 확인합니다.
4. `마크시트 인쇄`를 누릅니다.

주의: 이 인쇄표는 공식 마크시트 양식이 아니라, 수동 마킹을 돕기 위한 보조표입니다.

## 12. 자주 하는 실수

### Q1. 번호 생성이 안 됩니다.

조건이 너무 강한 경우입니다.

해결 방법:

- 제외 숫자를 줄입니다.
- 합계 범위를 넓힙니다.
- 홀짝 조건을 “상관없음”으로 바꿉니다.
- 최근회 중복 최대값을 늘립니다.

### Q2. 참고 점수가 높은 숫자만 고르면 되나요?

아닙니다. 점수 높은 숫자만 고르면 조합이 한쪽으로 쏠릴 수 있습니다.  
합계, 홀짝, 구간, 연번, 끝자리 분포를 같이 봐야 합니다.

### Q3. 백테스트가 랜덤보다 낮게 나왔습니다.

그 전략이 해당 기간에서는 랜덤보다 좋지 않았다는 뜻입니다.  
다른 전략, 다른 검증 회차 수, 다른 구수로 비교해보세요.

### Q4. 데이터가 최신인지 어떻게 확인하나요?

대시보드의 최신 추첨일과 공식 결과 사이트의 최신 회차를 비교하세요.  
실제 구매 전에는 반드시 공식 결과를 확인해야 합니다.

## 13. 추천 운영 방식

개인 테스트 단계에서는 단일 `index.html`로 충분합니다.

서비스화 단계에서는 다음 구조를 추천합니다.

1. `index.html`은 화면만 담당
2. `results.json`은 결과 데이터 담당
3. GitHub Actions로 매주 자동 업데이트
4. 공식 결과와 보조 출처를 교차 검증
5. 정적 호스팅으로 무료 배포
6. 이후 회원 기능, 알림, 커뮤니티는 후순위로 추가

## 19. 초보자용 아주 쉬운 설명

> 조건을 넣어 번호를 만들어보고,  
> 그 방법이 과거에는 어땠는지 확인하는 도구입니다.

중요한 점은 이 사이트가 당첨번호를 맞혀주는 사이트가 아니라는 것입니다.  
복권은 무작위 게임이고, 이 사이트는 판단을 도와주는 분석 도구입니다.

### 제일 먼저 볼 것

1. **최신 결과**  
   가장 최근에 어떤 번호가 나왔는지 봅니다.

2. **참고 점수 TOP 10**  
   과거 데이터 기준으로 눈여겨볼 만한 숫자를 봅니다.  
   점수가 높다고 반드시 나온다는 뜻은 아닙니다.

3. **핫 넘버**  
   과거에 자주 나온 숫자입니다.

4. **장기 미출현**  
   오래 나오지 않은 숫자입니다.

5. **상성 페어**  
   같이 나온 적이 많은 숫자쌍입니다.

## 21. 초보자 추천 사용 순서

### 1단계: 대시보드 보기

먼저 대시보드에서 최신 결과와 당첨금을 봅니다.

확인할 것:

- 최신 회차
- 본숫자 5개
- 보너스 숫자
- 1등~4등 당첨금
- 참고 점수 TOP 10

### 2단계: 번호 생성하기

처음에는 설정을 많이 바꾸지 마세요.

추천 기본값:

| 항목 | 값 |
|---|---|
| 생성 방식 | 균형형 |
| 생성 구수 | 10구 |
| 합계 | 55~105 |
| 홀수 | 3개 |
| 최대 연번쌍 | 2 |
| 동일 끝자리 최대 | 2 |

### 3단계: 마음에 드는 조합 고르기

생성된 조합에서 아래를 봅니다.

- 합계가 너무 낮거나 높지 않은가?
- 홀수/짝수가 너무 한쪽으로 몰리지 않았는가?
- 1~10, 11~20, 21~31 구간이 너무 한쪽으로 몰리지 않았는가?
- 연속 숫자가 너무 많지 않은가?
- 끝자리가 너무 반복되지 않았는가?

### 4단계: 전문 분석으로 확인하기

전문 분석에서 조합 밸런스 체크를 해봅니다.

A 또는 B 정도면 비교적 균형이 좋은 조합입니다.  
C 또는 D가 나쁘다는 뜻은 아니지만, 한쪽으로 치우친 조합일 수 있습니다.

### 5단계: 인쇄하고 추첨 후 확인하기

마음에 드는 조합만 인쇄목록에 추가합니다.  
추첨 후에는 당첨 확인 탭에서 내 번호를 붙여넣고 결과를 확인합니다.

## 23. 초보자가 자주 하는 오해

### 참고 점수가 높으면 꼭 나오나요?

아닙니다. 참고 점수는 과거 데이터 기준으로 계산한 값입니다.  
다음 회에 나올 확률을 보장하지 않습니다.

### 오래 안 나온 숫자는 곧 나오나요?

아닙니다. 오래 안 나왔다는 사실만 보여주는 것입니다.  
복권은 매회 무작위입니다.

### 백테스트가 좋으면 앞으로도 좋은가요?

반드시 그렇지 않습니다.  
백테스트는 과거 실험입니다. 미래 결과를 보장하지 않습니다.

### 조합 밸런스 A가 당첨 확률이 높은가요?

아닙니다. A는 균형이 좋다는 뜻이지 당첨 확률이 높다는 뜻은 아닙니다.

### 많이 사면 반드시 맞나요?

아닙니다. 구입 수가 늘면 이론 확률은 조금 올라가지만, 당첨을 보장하지 않습니다.  
반드시 정한 예산 안에서만 이용하세요.
