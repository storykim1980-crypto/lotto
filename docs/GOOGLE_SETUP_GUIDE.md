## 2. 구글 서치콘솔 등록 (검색엔진 등록) — 10분

1. 브라우저에서 **https://search.google.com/search-console** 접속 → 구글 계정(storykim1980@gmail.com)으로 로그인.
2. 왼쪽 위 **「속성 추가」(プロパティを追加)** 를 누릅니다.
3. 두 가지 방법 중 **「URL 접두어」** 를 고르는 게 쉽습니다:
   - 입력: `https://miniloto-navi.com`
4. **소유권 확인** 화면이 나옵니다 → **「HTML 태그」** 를 선택하면 아래 같은 코드가 보입니다:
   ```html
   <meta name="google-site-verification" content="AbCdEf123..." />
   ```
5. 그 코드의 **`content="..."` 안의 값만 복사**해서, 저에게 말해주거나 직접 `index.html` 상단의 주석에 붙여넣습니다:
   ```html
   <!-- 현재 index.html 안에 이미 준비된 자리 -->
   <meta name="google-site-verification" content="여기에_붙여넣기" />
   ```
6. GitHub에 저장(push)하면 Cloudflare Pages가 자동 재배포 (1~2분).
7. 서치콘솔로 돌아와 **「확인」** 버튼 클릭 → **"소유권이 확인되었습니다"** 가 뜨면 성공.
8. 왼쪽 메뉴 **「Sitemap」** → `sitemap.xml` 입력 → 제출. (이걸 해야 구글이 페이지를 빨리 수집합니다)

> ※ 도메인 구입 직후에는 DNS(도메인 연결)가 퍼지는 데 몇 시간~하루 걸릴 수 있습니다.
> ※ 추천: **「도메인」方式**(네임서버 방식)으로도 한 번 더 등록하면 `www` 유무 둘 다 커버됩니다.

## 4. 애드센스 심사 신청 — 사이트 배포 후 바로

- ✅ 소개 페이지(運営者情報, 문의 이메일 명시)
- ✅ 개인정보처리방침 + 쿠키 정책 (AdSense·GA·옵트아웃 링크 전부 명시)
- ✅ 이용약관 + 면책사항 (비공식·당첨보장없음 명확 표기)
- ✅ 광고 정책 (광고에 대한 입장, "広告" 표기 원칙)
- ✅ 풍부한 고유 콘텐츠 (1397회 데이터 + 통계 + 사용법 가이드)

## 5. 승인 후 — 광고 단위 만들어 slot 번호 교체 (5분)

승인 메일이 오면:

1. 애드센스 → **「広告」→「広告ユニットごと」→「ディスプレイ広告」**.
2. 이름을 `navi-top` 처럼 지어 만들면 **10자리 slot 번호**(예: `1234567890`)와 코드가 나옵니다.
3. `index.html`을 열어, 아래 3곳의 숫자만 발급받은 번호로 바꿉니다 (찾기: `data-ad-slot`):

| 광고 자리 | 현재 값 | 교체할 것 |
|---|---|---|
| 상단 배너 | `1111111111` | 애드센스에서 만든 1번 단위 slot |
| 본문 중간 | `2222222222` | 2번 단위 slot |
| 하단 배너 | `3333333333` | 3번 단위 slot |

4. 저장 → GitHub push → 1~2분 후 사이트에 실제 광고 표시.

> **slot 교체 전이라도 사이트는 정상 작동**합니다. 빈 자리에 "広告" 라벨과 깔끔한 점선 박스만 보입니다. (방문자 화면을 망가뜨리지 않게 디자인해 뒀습니다)
